# Real-Time Intelligent Work Allocation System

A web-based real-time work allocation system that intelligently assigns tasks to employees based on skills, workload, availability, priority, and deadlines.

## Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Python
- FastAPI
- WebSockets

### Database
- PostgreSQL
- SQLAlchemy

### Intelligence
- Rule-based allocation
- Machine Learning / AI (planned)

## Features

- User authentication
- Employee management
- Skills management
- Task management
- Intelligent task allocation
- Real-time task updates
- Workload monitoring
- Notifications
- Analytics dashboard
